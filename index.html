音声は合成音声です（会話文は2人の声で読み分け）。→ や = でつながる書き換えは順番に読み上げます。( ) 内の語は基本的に読み上げ、who / whom のような選択肢は最初の語だけを読みます（Lesson 30「省略」では ( ) 内を読みません）。* 付きの誤用例と、Lesson 3 §4 の表は音声がありません。英文・和訳を隠しているときは、その部分をタップすると表示されます。
